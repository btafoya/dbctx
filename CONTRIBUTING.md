# CONTRIBUTING.md

Thank you for contributing to dbctx.

## Workflow

1.  Discuss significant ideas through an RFC.
2.  Wait for acceptance before implementation.
3.  Submit focused pull requests.
4.  Include documentation and tests.

## Standards

-   rustfmt
-   clippy (warnings denied)
-   nextest
-   Snapshot updates reviewed
-   New behavior requires tests

## Commit Style

Conventional Commits are recommended.

## Pull Requests

Every PR should include: - Problem statement - Design summary - Tests -
Documentation updates - Breaking-change notes (if applicable)

## Code Review

Review for: - Correctness - Simplicity - Determinism - Performance - API
stability - Documentation

## Code of Conduct

Be respectful, constructive, and inclusive.
