# RFC Process

RFCs describe proposed changes before implementation.

## Lifecycle

Draft → Discussion → Accepted/Rejected → Implemented

## Required Sections

-   Summary
-   Motivation
-   Design
-   Alternatives
-   Drawbacks
-   Compatibility
-   Unresolved Questions

Accepted RFCs update SPEC.md when implemented.

Suggested numbering:

RFC/ ├── 0001-core-cli.md ├── 0002-postgresql.md └── ...
