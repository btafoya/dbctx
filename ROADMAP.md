# dbctx Roadmap

## v0.1 -- Foundation

-   Rust library + CLI
-   MySQL/MariaDB/SQL Server support
-   INFORMATION_SCHEMA introspection
-   JSON, Markdown, Mermaid exporters
-   Validation, stats, diff
-   Optional --analyze and --llm
-   Docker Compose autodiscovery
-   Stable format v1.0

## v0.2

-   Performance improvements
-   Better diagnostics
-   More validation rules
-   Configuration file

## v0.3

-   PostgreSQL
-   SQLite
-   Additional exporters

## v1.0

-   Stable public API
-   Stable format 1.x
-   Production-ready documentation

## Future

-   Template engine
-   Plugin architecture
-   MCP resources
-   IDE integrations
-   RAG exports

## Release Policy

-   Semantic Versioning
-   RFCs for major features
-   ADRs for architecture
-   Format versions evolve independently.
